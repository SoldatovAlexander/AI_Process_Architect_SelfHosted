## Правила использования каталога

1. n8n workflow является **источником реализации**, но не канонической бизнес-моделью.
2. При импорте сохраняем provenance: template ID, URL, исходное название и дату получения.
3. Credentials, секреты, canvas coordinates, sticky notes и чисто визуальные метаданные не входят в semantic graph.
4. Конкретные SaaS заменяются ролями адаптеров: `crm`, `email`, `messenger`, `calendar`, `file_storage`, `accounting`, `task_tracker`, `llm` и т. п.
5. Один бизнес-процесс может иметь несколько implementation profiles: например Bitrix24/amoCRM; Telegram/VK Teams; 1С/PostgreSQL; Yandex 360/SMTP.
6. Перепубликация исходного JSON допускается только после отдельной проверки лицензии конкретного шаблона.
