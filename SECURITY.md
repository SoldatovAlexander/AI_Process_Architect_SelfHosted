# Security policy

Do not report vulnerabilities through a public issue before a mitigation is available. Use a private
security advisory in this repository and include the affected version, a safe reproduction with synthetic
data, impact, and whether the issue concerns the self-hosted package or the closed licence issuer.

Never attach customer data, access tokens, activation codes, licence envelopes, private keys, or database
dumps to a report.

The self-hosted package will support signed offline licences and optional HTTPS online activation. The
licence issuer and its Ed25519 private key are not distributed to customers.
