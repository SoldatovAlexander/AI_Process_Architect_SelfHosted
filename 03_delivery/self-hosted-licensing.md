# Community Self-hosted: licensing boundary

## Русский

Community Self-hosted не использует лицензию, activation code, подписанный envelope, License Control
Plane, ключи issuer или список отзыва. После запуска все режимы работы сервиса доступны без активации.

Community ограничивает только пользовательские выгрузки: доступны BPMN/draw.io и текстовое описание
процесса. Экспорт n8n-workflow и Agent-ready пакетов заблокирован сервером и не отображается в интерфейсе.
Создание проектов, работа с интервью, Process IR, пользовательскими или локальными LLM, шаблонами,
генерацией кода, runtime-подключениями и агентскими сценариями не требуют лицензии.

Этот файл сохраняет границу продукта: если в будущем появится коммерческая поставка, её механизм
лицензирования должен быть отдельным от Community-репозитория и не должен менять доступность Community.

## English

Community Self-Hosted uses no license, activation code, signed envelope, License Control Plane, issuer
key, or revocation list. After startup, all service work modes are available without activation.

Community limits only user-facing exports: BPMN/draw.io and a text process description are available.
n8n workflow and Agent-ready package exports are blocked by the server and hidden in the interface.
Projects, interviews, Process IR, user-provided or local LLMs, templates, code generation, runtime
connections, and agent scenarios require no license.

If a commercial edition is introduced later, its licensing mechanism must stay separate from this
Community repository and must not alter Community availability.
